# Quick Panel

Windows 原生快捷面板，用一个搜索框查找功能、剪贴板内容、常用文件夹和文档。Rust、Win32 原生控件与 SQLite；新历史先在内存里可用，再低频批量保存。

## 在 Windows 使用

将 dist/QuickPanel-Windows-x64.zip 复制到 Windows x64 电脑，解压后双击 QuickPanel.exe。程序常驻系统托盘，可通过托盘图标或快捷键打开面板。此包面向 Windows 10 和 Windows 11。

| 操作 | 默认方式 |
|---|---|
| 打开面板 | Ctrl+Alt+Space，或点击托盘图标 |
| 移动选择 | 上下方向键 |
| 执行功能、打开文件或粘贴历史 | Enter，或双击结果 |
| 更多动作 | 右键结果 |
| 添加收藏 | 搜索“添加文件夹”或“添加文档”，也可使用添加按钮或拖入文件 |
| 关闭面板 | Esc、关闭按钮或点击面板外 |
| 真正退出 | 搜索“退出”并执行“保存后退出”，或使用托盘菜单 |

在搜索框输入“快捷键”或“设置”即可打开设置。两组全局快捷键都可修改，留空并保存即可关闭；新安装默认仅启用呼出键，剪贴板专用热键默认关闭。升级保留已经明确保存的组合，可在设置中手动留空关闭。修改注册失败时保留原有热键，保留系统 Win+V；关闭全部热键后仍能从托盘打开。注册失败提示不能识别所有软件内部快捷键冲突，遇到冲突可更换组合或关闭。

可选的面板内按键：Shift+Enter 纯文本粘贴，Ctrl+C 复制（搜索框有文本选区时优先复制文字），Ctrl+K 打开更多动作，Ctrl+1 至 Ctrl+4 切换保存内容范围。这些按键只在面板内生效，日常操作可以通过结果、按钮和右键菜单完成。

主题可选择跟随系统、浅色或深色；设置中可以暂停记录及排除指定应用。收藏支持名称、别名、标签、打开方式和目标重新定位。固定的剪贴板条目右键可编辑名称、别名和标签，三个字段都是原生输入框；取消、关闭或目标变化不会提交，正文和原始格式保持原样。未固定的条目可先从右键菜单固定。名称为 1–160 字符，别名最多 128 字符，标签最多 32 个、每个最多 64 字符；会去掉首尾空白、合并重复标签，并拒绝控制字符。

图片与文本预览按需打开，隐藏面板会释放图片预览。文本预览是只读原生输入框，可以选取局部文字并用 Ctrl+C 复制，输入法和方向键继续由原生控件处理。

中文输入框使用原生控件；输入法选词时，回车、Esc 和方向键先交给输入法。已展示结果保持当前选择，不因后台新增历史跳到另一项。

## 统一检索

搜索框同时返回功能和保存内容，每条结果保留标题及“功能、剪贴板、文件夹、文档”类别。第二行显示来源、命中片段和本地保存时间；命中正文时缩短前文，让匹配位置尽早可见，长别名和标签不会占据核心标题。输入中文、拼音、首字母或关键词即可查找，按 Enter 执行当前结果对应的动作。

| 输入示例 | 功能或内容 |
|---|---|
| 设置、快捷键、shezhi、sz | 打开设置 |
| 添加文件夹、tjwjj | 选择目录并收藏 |
| 添加文档 | 选择文件并收藏 |
| 暂停记录、恢复记录 | 根据当前状态暂停或恢复捕获 |
| 预览 | 展开或收起预览区 |
| 剪贴板、文件夹、文档、全部 | 切换保存内容范围 |
| 周报、zhoubao、zb | 查找相应的保存内容 |

明确匹配名称或别名的功能优先展示，同名的保存内容仍可选择。范围按钮过滤保存内容，功能在各范围内均可检索。空搜索优先显示保存内容，没有内容时提供添加与设置入口。

剪贴板可检索正文，收藏可检索名称、路径、别名和标签。当前不解析 Word、PDF 等文件内部全文。功能目录只在内存中匹配，搜索不会把功能写入 SQLite，也不会提前保存待提交的历史。

## 统一智能查找

主搜索栏只有一个“智能查找”按钮；输入文字仍然即时执行普通本地搜索。只有明确点击智能按钮或执行对应的功能结果，才可能发送本次查询。未启用任何能力时，按钮进入配置选择，两个独立服务的 API 设置和“测试连接”均保留。

常规设置可选择首选能力：

| 首选能力 | 点击“智能查找”后的行为 |
|---|---|
| Auto / 自动 | 已启用语义检索且有有效索引时优先查相似内容，否则使用已启用的 Claude；只有 Embedding 且没有索引时引导建立索引 |
| Claude | 理解检索描述，再查本机内容和功能；未启用时打开 Claude 配置 |
| Semantic / 语义 | 查询已建立的索引；未启用时打开语义配置，没有有效向量时引导建立索引 |

索引状态在后台取得并缓存在内存中，显示“未建立可用索引”“已索引 N 条”或“待更新”。点击这行可明确建立/更新索引，更新期间可取消；也可以搜索“建立索引”“更新语义索引”。状态刷新只在启动、显示、内容/配置变更及显式操作后按需合并，输入每个字不会扫描索引。0 个有效向量时不发送 Embedding 查询，也不会自动建立索引。

正在检查索引或请求服务时，同一个按钮显示“取消智能”，可立即撤销本次操作；修改查询、切换范围、打开配置、隐藏或退出也会撤销。已采用的智能结果可用该按钮返回本地模式。取消后的在途服务可能仍完成，但旧回复和旧索引状态回执不会触发新查询。API 故障安静回到本地搜索，具体原因可在对应设置里测试连接；真实存储错误仍会显示。

搜索“按意思查找”会得到明确标为 Claude 的功能结果，“语义查找”会得到已建索引策略的功能结果；“智能查找”使用常规设置中的首选能力。这些入口共用取消和结果保护规则。

## 可选 AI 按意思查找

AI 默认关闭。点击“设置 ▾ → AI 检索设置”，或搜索“AI设置”“Claude配置”打开配置。填写服务商提供的模型 ID 和 API Key，勾选启用后保存。

| 配置 | 说明 |
|---|---|
| API 地址 | 官方可用 https://api.anthropic.com；也支持兼容网关的根地址、/v1 或完整 /v1/messages，自定义路径前缀保留 |
| 模型 ID | 填写该接口实际支持的模型名称 |
| 认证方式 | 默认 x-api-key；兼容网关需要时选择 Bearer token |
| API Key | 密码输入框不回填密钥，留空保留原密钥；可用清除选项删除并关闭 AI |

启用后，在搜索框描述想找什么，再点击“智能查找”；首选能力选 Claude 时使用本服务。普通结果保持可用；再次点击“取消智能”、修改查询、切换范围或隐藏面板，会停止采用旧请求的回复。在途服务请求可能仍然完成，软件不自动重试。

API 连接、认证或响应异常时，搜索页安静回到本地检索，不反复显示接口错误。可在 AI 检索设置中点击“测试连接”，查看具体失败原因或成功耗时。测试使用当前填写但尚未保存的地址、模型、认证方式和密钥；密码留空使用已保存密钥，选择清除密钥后禁止测试。即使功能尚未启用，也能先测试再保存。

例如“我想暂时停止记录复制内容”可以推荐已有的“暂停记录”功能；“昨天保存的连接超时处理说明”可以改写为关键词并筛选历史。AI 推荐的功能只是可选结果，按 Enter 才执行。模型不生成虚构的历史条目或文件路径。

该功能使用 [Claude Messages API](https://platform.claude.com/docs/en/api/messages/create) 格式，仅发送本次查询、当前范围和公开功能目录，不上传历史正文、文件内容或图片。它将模型返回的短关键词、同义词和范围交给本地检索，此 Claude 功能不使用向量索引或文档 RAG。时间筛选按首次保存时间；今天、昨天及近 7/30 天使用 Windows 本地日期，近 7/30 天包含今天。

API Key 使用当前 Windows 用户的 DPAPI 保护后，随设置立即保存。AI 计划和回复只存在于内存，不因检索写入 SQLite。复制数据库到其他 Windows 账户或设备后，可能需要重新填写密钥。网络和加密原生测试在此 macOS 开发环境仅交叉编译，真实接口与 Windows 交互仍需验收。

## 可选语义检索（独立 Embedding API）

语义检索默认关闭，配置与 Claude 独立。打开“设置 ▾ → 语义检索设置”，也可搜索“语义检索设置”。填写 OpenAI 兼容 Embedding API 地址、模型 ID 与 API Key，选择索引范围并启用。密钥由当前 Windows 用户的 DPAPI 保护；密码框留空保留原密钥，清除密钥同时关闭语义检索。保存只在本机校验配置与密钥，不发送网络请求。

语义检索设置也提供“测试连接”，成功后显示向量维度和耗时。两个测试按钮每次仅发送一条内置测试文本，可能消耗服务额度；不发送历史或文件内容，不保存配置或写入索引。测试在后台运行，期间可取消关闭；重复点击不会叠加请求，关闭后的旧结果不再显示。测试失败原因只在设置表单显示；检索接口异常时继续使用本地结果，索引接口异常会停止本次更新，需手动再次启动。磁盘和保存错误仍会提示。

先从索引状态行、设置菜单或功能搜索执行“建立/更新语义索引”，再输入描述并点击“智能查找”。首选能力 Auto 有有效索引时优先使用语义，Semantic 始终使用该策略。输入时仍然即时执行普通本地检索；只有明确执行智能查找才发送查询。默认索引“固定内容与收藏”，可改为“全部文本”。索引不会因启动、复制、输入自动发起，已完成且输入未变的条目会跳过。源内容变化后，显式更新索引可补齐缺失或变化的向量。

**发送范围：**建立索引将选定范围的保存文本，以及保存的名称、别名、标签和路径发送给你配置的独立 Embedding 服务；查询仅发送本次描述。文档与文件夹只索引这些已保存元数据，不读取或解析文件正文；不发送图片和 HTML/RTF 二进制表示。每条派生输入最多 4096 字符（含元数据），原始内容不截断；仅有图片、没有可见文字的剪贴板不索引。

| 协议与预算 | 行为 |
|---|---|
| 地址 | 支持根地址、`/v1`、完整 `/v1/embeddings` 和代理前缀；远程要求 HTTPS，HTTP 仅允许本机 loopback |
| 请求 | Bearer Key；POST JSON 为 `model`、字符串数组 `input`、`encoding_format: "float"`；模型 ID 由用户填写 |
| 批次 | 一次最多 16 条、请求体最多 512 KiB；响应最多 2 MiB，向量维度 1–4096 |
| 结果 | 按响应 `index` 对齐输入；有限、非零且维度一致的向量；不显示服务错误正文，不自动重试 POST |

再次点击“取消智能”、修改查询、切换范围、打开设置或隐藏面板会立即撤销旧查询与已经采用的语义结果。普通检索可继续使用。在途网络可能仍完成，但过期回复不会进入结果。Claude 与语义查询互相撤销旧模式。

索引与查询独立；隐藏面板或编辑查询可以保留用户启动的索引。设置菜单中的“取消索引”、确认修改 Embedding 配置或退出会停止后续批次，保留已接收向量。每批收到存储接收回执后才继续；错误停止会话，需用户明确更新后再试。退出保存原文与已接收向量，不等待未完成的网络。

派生向量通过静态链接的 sqlite-vec **0.1.9** 存入本机 SQLite；按模型/地址 profile 和输入哈希隔离，删除及内容变化排除旧向量。检索合并词法与余弦候选，保持引擎的混合排序，最多返回 50 个真实保存条目。向量沿用约 55 秒开始、健康情况下 60 秒窗口的低频批量保存，派生缓存最多 4 MiB，压力时可提前提交；收藏与配置仍立即保存。

共享协议、worker、存储、排序和会话回归在 macOS 运行；Windows 本地 TCP/DPAPI fixtures 仅交叉检查编译，未执行 WinHTTP、DPAPI 或 GUI。真实服务的模型效果、费用和延迟以及 Windows 操作需实机验收；人工向量测试不能证明中文语义效果。

## 数据和保存

数据位于 %LOCALAPPDATA%/QuickPanel/quick-panel.sqlite3 及 SQLite 的同目录 WAL 文件。历史和收藏保存在本机，当前没有云同步或整个数据库的磁盘加密；Claude 查询与语义查询/索引的发送范围见上节。来源应用声明的敏感剪贴板标记会被排除，也可以手动排除应用；这依赖来源应用正确提供标记。

- 历史进入内存后立即可查、可复制和粘贴。默认约 55 秒开始批量提交，预留提交裕量；正常磁盘响应下保存窗口不超过 60 秒，连续复制不会延期。
- 收藏及其删除、确认后的配置立即保存。使用次数合并更新，随批次保存。
- 没有数据变更时不提交空事务，不周期性重写配置、日志或缩略图。
- 图片原始表示与数据库引用在同一个事务内保存。缩略图仅作内存缓存，不因预览写盘。
- 图片保留的总负载上限 8 MiB；有 PNG 原图时，过大的可选 DIB 表示可跳过而保留 PNG，只有 DIB 且超预算仍不支持。预览源上限 100 MP，缩略图长边最多 1024、输出最多 4 MiB；可选粘贴兼容 DIB 最多 64 MiB，超限保留原图并安静退回可用格式。这些是应用自身数据预算，不是进程总 RSS 的承诺。
- 待保存内容及捕获队列各有 16 MiB 预算，单条捕获总表示和派生文字上限 8 MiB；接近预算时提前保存。超限时说明未记录，不截断当前剪贴板。
- 正常退出先排空已接受任务并保存全部待保存内容，收到成功确认后才结束进程。失败时等待用户重试或取消退出，缓存继续保留；取消后恢复后台保存。
- 任务管理器强制结束、系统故障或断电可能丢失尚未提交的数据。Windows 结束会话执行有界保存，不能等同正常退出。

备份时先正常退出程序，再复制整个 QuickPanel 数据目录。

## 构建和验证

在 Windows 安装 Rust 和 Visual Studio C++ 构建工具后：

    cargo test --locked
    cargo clippy --locked --all-targets -- -D warnings
    powershell -ExecutionPolicy Bypass -File scripts/build-windows.ps1

在安装 Rust GNU Windows 目标及 MinGW 的 macOS/Linux 上：

    rustup target add x86_64-pc-windows-gnu
    bash scripts/build-cross.sh

共享核心可在非 Windows 环境运行：

    cargo run --release -- --core-check
    cargo run --release -- --benchmark 10000
    cargo run --release -- --benchmark 100000

core-check 使用临时数据库验证保存前可检索、保存前磁盘没有历史条目，以及退出后能够恢复。benchmark 写入明确数量的混合中文、拼音、路径记录，输出 100 次核心查询的 p50、p95 和最大值；不包含 Windows 窗口与渲染延迟。基准准备阶段主动分批保存，以限制输入队列内存，不代表日常自动保存频率。

自动测试覆盖低频提交、真实 SQLite 故障重试、退避与缓存预算、退出恢复、中文短查询和拼音检索、格式解析与面板状态。Windows CI 配置位于 .github/workflows/windows.yml；本地交叉构建成功不等于该 CI 已运行。

本轮便携状态、策略选择和元数据行为测试在 macOS 执行；Windows 原生控件与服务 fixtures 仅严格 Clippy/交叉编译检查，GUI 未实机执行。实际 Windows 输入法、多屏 DPI、托盘、图片绘制、不同权限窗口粘贴和系统关机需要实机验收。程序使用普通权限；自动粘贴遇到权限或焦点限制时保留已复制内容并说明手动粘贴。
