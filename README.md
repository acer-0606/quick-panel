# Quick Panel

Windows 原生快捷面板，用一个搜索框查找功能、剪贴板内容、常用文件夹和文档。Rust、Win32 原生控件与 SQLite；新历史先在内存里可用，再低频批量保存。

## 在 Windows 使用

将 dist/QuickPanel-Windows-x64.zip 复制到 Windows x64 电脑，解压后双击 QuickPanel.exe。程序常驻系统托盘，可通过托盘图标或快捷键打开面板。此包面向 Windows 10 和 Windows 11。

| 操作 | 默认方式 |
|---|---|
| 打开面板 | Ctrl+Alt+Space，或点击托盘图标 |
| 移动选择 | 上下方向键 |
| 执行功能、打开文件或粘贴历史 | Enter，或双击结果 |
| 更多动作 | 右键结果 |
| 添加收藏 | 搜索“添加文件夹”或“添加文档”，也可使用添加按钮或拖入文件 |
| 关闭面板 | Esc、关闭按钮或点击面板外 |
| 真正退出 | 搜索“退出”并执行“保存后退出”，或使用托盘菜单 |

在搜索框输入“快捷键”或“设置”即可打开设置。面板、剪贴板专用、区域截图三组快捷键统一在“设置中心 → 常规与快捷键”中修改；三组都可留空并保存关闭。新安装默认仅启用呼出键，剪贴板专用与截图热键默认关闭。升级保留已经明确保存的组合，可在设置中手动留空关闭。修改注册失败时保留原有热键，保留系统 Win+V；关闭全部热键后仍能从托盘打开。注册失败提示不能识别所有软件内部快捷键冲突，遇到冲突可更换组合或关闭。

可选的面板内按键：Shift+Enter 纯文本粘贴，Ctrl+C 复制（搜索框有文本选区时优先复制文字），Ctrl+K 打开更多动作，Ctrl+1 至 Ctrl+4 切换保存内容范围。这些按键只在面板内生效，日常操作可以通过结果、按钮和右键菜单完成。

主题可选择跟随系统、浅色或深色；设置中可以暂停记录及排除指定应用。收藏支持名称、别名、标签、打开方式和目标重新定位。固定的剪贴板条目右键可编辑名称、别名和标签，三个字段都是原生输入框；取消、关闭或目标变化不会提交，正文和原始格式保持原样。未固定的条目可先从右键菜单固定。名称为 1–160 字符，别名最多 128 字符，标签最多 32 个、每个最多 64 字符；会去掉首尾空白、合并重复标签，并拒绝控制字符。

图片与文本预览按需打开，隐藏面板会释放图片预览。文本预览是只读原生输入框，可以选取局部文字并用 Ctrl+C 复制，输入法和方向键继续由原生控件处理。

中文输入框使用原生控件；输入法选词时，回车、Esc 和方向键先交给输入法。已展示结果保持当前选择，不因后台新增历史跳到另一项。

## Pi 整理与记忆

“AI 管家设置”中的整理默认关闭；启用后按需启动便携包内的 Pi/Node 运行时，结束即退出。请完整解压并保留 `runtime` 目录；使用时不下载运行时，不需要全局安装 Node。“测试 Pi 运行时”只检查本地启动和协议，不调用模型。

沿用服务连接中 Claude 的模型、推理强度和当前用户保护的密钥；密钥只在 Rust 网络层使用。Pi 只能调用六个整理业务工具，建议须经本地来源校验和完整提交才能应用。“AI 管家 → 高级调度参数”可选择 2–8 个模型轮次，默认 4；每批最多 32 次工具调用，活动时间最多 120 秒。认证或缺少运行时会暂停新的自动整理；修复后点击重试。单批达到预算会显示“需处理”，后面的来源继续整理。

在“整理建议”中选中已完成建议或需处理内容，点击“反馈并重做”，填写 1–256 字符的原因并明确选择仅此内容、同目录或全局。默认仅此内容；保存时将换行和制表符转为空格。来源或所见建议已变化时会保留输入并提示；“忽略建议”只终结当前版本建议，不学习偏好，也不会因普通重试重新出现。关闭“启用整理记忆（使用规则并记录反馈）”会停止使用已有规则并停止记录新反馈；重新启用后才可保存新反馈，已提交操作仍可重试保存；保存重试不会取消后来开始的整理任务。

搜索“AI 整理记忆”或从建议页进入，可查看来源、范围、依据，编辑/停用/删除规则（规则最多 512 字符），明确确认 AI 草稿。小屏或高 DPI 时内容区可以滚动，Tab 会把当前字段滚入视野，底部保存、重试、删除和关闭按钮保持独立可见。保存失败保留原输入，点击“重试保存”会使用原操作标识，不重复记录；只有对应回执确认提交后显示已保存。采用、修改后采用和自动整理各自保留来源含义，没有新增全局热键。

退出会保存已接收的检查点及本地缓存，并清理属于本程序的运行时，不等待模型。崩溃恢复可能重算尚未保存的进展；不能保证远端 API 不重复计费。实际 Windows 原生窗口、WinHTTP 和 Job 对象需要 Windows 实机验收；当前开发环境只运行共享核心/真实合成子进程测试和 Windows 交叉编译。

## 区域截图

搜索“截图”“区域截图”或“screenshot”，也可从托盘菜单进入。面板隐藏后拖动选择屏幕区域，松开鼠标确认；Esc、右键、失去鼠标捕获或显示器布局变化会取消。选区支持虚拟桌面的负坐标及不同 DPI 的屏幕，确认后先隐藏选区层，再读取所选区域；不缓存整个桌面、不持续抓屏。取消后恢复先前应用的合理焦点，不自动弹出面板。

图片在内存中编码为 PNG，并同时提供兼容位图剪贴板格式，可以直接粘贴到支持图片的应用；不创建临时图片文件或伪造文件路径。截图原始 BGRA 像素最多 64 MiB（例如 4096×4096），交付 PNG 最多 8 MiB。编码一次只处理一张；占用、分配或编码预算失败会提示。等待编码期间若复制了新内容，截图不会覆盖它，最终在锁定剪贴板后重新检查序号。

搜索“截图快捷键设置”可启用可选全局热键，默认关闭，留空保存可关闭。截图复制不受“暂停剪贴板记录”限制，但暂停时不会保存到历史；来源应用排除规则仍生效，来源沿用真实剪贴板所属进程文件名（通常为 QuickPanel.exe）。允许记录时只提交一次 PNG 到原有历史，不持久保存大型兼容位图。

截图与编码无需联网或模型。屏幕内容在选区与实际读取之间可能变化；受保护窗口、硬件视频层、不同权限窗口以及实际多屏 DPI、焦点和剪贴板接收应用仍需 Windows 实机验收。开发主机仅运行便携几何与生命周期测试、交叉检查原生编码 fixtures，没有抓取用户屏幕或访问用户剪贴板。

## 外部常用路径推荐（可选）

搜索“常用推荐设置”，或打开“设置中心 → 常用路径”，启用“常用推荐”；新安装默认关闭，无需先添加收藏。启用后以本工具之外、处于前台的 Windows 资源管理器目录为主来源：每两秒观察一次，目录稳定停留至少 1.5 秒才记录一次有效访问。同一窗口重新聚焦同一目录不重复计次，导航到其他目录或新开窗口可形成新访问。它不是系统全部打开操作的审计记录。

Windows 11 标签页只接受能可靠识别的当前活动可见 Shell 视图；隐藏视图、歧义视图、虚拟目录均跳过。第三方文件管理器不在主来源覆盖范围。可选 Recent 仅以目录变化信号为补充，首次建立最多 2048 条链接元数据基线，不回放旧目标；一次最多解析 16 个新增或修改链接。超过此边界、截断、含环境变量或无法明确识别的目标跳过，不读取目标正文、检测目标存在性或为统计触发网络探测。

自动结果标为“常用文件夹/常用文档”和“外部观察”，时间是最近访问时间；空查询最多 5 项、有输入最多 10 项，与当前结果里的人工收藏按规范路径去重，总结果仍最多 50 项。已固定或匹配的人工条目保持优先。同名目录在本次结果中突出不同的中间目录或根路径；已有别名优先，打开、复制及预览使用完整原路径。按 Enter 打开，右键或 Ctrl+K 可复制路径、打开所在目录、通过现有表单显式收藏，或选择“不再推荐此路径”。自动项只有在明确启用含路径范围的 AI 管家后才会发送整理摘要，不进入默认 Embedding 索引。

设置可独立关闭 Recent、按每行一条绝对路径排除目录（最多 128 条），以及清空统计。关闭常用推荐会停止观察并隐藏自动项；关闭、改配置和清空使已有探测结果失效。统计与本地排名保存在当前用户的本地数据库，沿用低频批量写盘；不新增默认全局快捷键。

## 统一检索

搜索框同时返回功能和保存内容，每条结果保留标题及“功能、剪贴板、文件夹、文档”类别。第二行显示来源、命中片段和本地保存时间；命中正文时缩短前文，让匹配位置尽早可见，长别名和标签不会占据核心标题。输入中文、拼音、首字母或关键词即可查找，按 Enter 执行当前结果对应的动作。

| 输入示例 | 功能或内容 |
|---|---|
| 设置、快捷键、shezhi、sz | 打开设置 |
| 添加文件夹、tjwjj | 选择目录并收藏 |
| 添加文档 | 选择文件并收藏 |
| 暂停记录、恢复记录 | 根据当前状态暂停或恢复捕获 |
| 预览 | 展开或收起预览区 |
| 剪贴板、文件夹、文档、全部 | 切换保存内容范围 |
| 周报、zhoubao、zb | 查找相应的保存内容 |

明确匹配名称或别名的功能优先展示，同名的保存内容仍可选择。范围按钮过滤保存内容，功能在各范围内均可检索。空搜索优先显示保存内容，没有内容时提供添加与设置入口。

剪贴板可检索正文，收藏可检索名称、路径、别名和标签。当前不解析 Word、PDF 等文件内部全文。功能目录只在内存中匹配，搜索不会把功能写入 SQLite，也不会提前保存待提交的历史。

## 统一智能查找

主搜索栏只有一个“智能查找”按钮；输入文字仍然即时执行普通本地搜索。只有明确点击智能按钮或执行对应的功能结果，才可能发送本次查询。未启用任何能力时，按钮进入配置选择，两个独立服务的 API 设置和“测试连接”均保留。

“设置中心 → 智能查找”可选择首选能力：

| 首选能力 | 点击“智能查找”后的行为 |
|---|---|
| Auto / 自动 | 已启用语义检索且有有效索引时优先查相似内容，否则使用已启用的 Claude；只有 Embedding 且没有索引时引导建立索引 |
| Claude | 理解检索描述，再查本机内容和功能；未启用时打开 Claude 配置 |
| Semantic / 语义 | 查询已建立的索引；未启用时打开语义配置，没有有效向量时引导建立索引 |

索引状态在后台取得并缓存在内存中，显示“未建立可用索引”“已索引 N 条”或“待更新”。点击这行可明确建立/更新索引，更新期间可取消；也可以搜索“建立索引”“更新语义索引”。状态刷新只在启动、显示、内容/配置变更及显式操作后按需合并，输入每个字不会扫描索引。0 个有效向量时不发送 Embedding 查询，也不会自动建立索引。

正在检查索引或请求服务时，同一个按钮显示“取消智能”，可立即撤销本次操作；修改查询、切换范围、打开配置、隐藏或退出也会撤销。已采用的智能结果可用该按钮返回本地模式。取消后的在途服务可能仍完成，但旧回复和旧索引状态回执不会触发新查询。API 故障安静回到本地搜索，具体原因可在对应设置里测试连接；真实存储错误仍会显示。

搜索“按意思查找”会得到明确标为 Claude 的功能结果，“语义查找”会得到已建索引策略的功能结果；“智能查找”使用“智能查找”组中的首选能力。这些入口共用取消和结果保护规则。

## 可选 AI 按意思查找

AI 默认关闭。点击“设置中心 → 服务连接 → 配置共用 Claude 连接”，或搜索“AI设置”“Claude配置”打开配置。填写服务商提供的模型 ID 和 API Key 并保存，再到“智能查找”组启用 Claude 按意思查找。

| 配置 | 说明 |
|---|---|
| API 地址 | 官方可用 https://api.anthropic.com；也支持兼容网关的根地址、/v1 或完整 /v1/messages，自定义路径前缀保留 |
| 模型 ID | 可手动填写，也可点击“获取模型”后选择服务返回的 ID；显示名称不会代替模型 ID |
| 推理强度 | 默认、low、medium、high、xhigh、max；默认省略 effort 参数，兼容性最佳 |
| 认证方式 | 默认 x-api-key；兼容网关需要时选择 Bearer token |
| API Key | 密码输入框不回填密钥，留空保留原密钥；可用清除选项删除并关闭 AI |

启用后，在搜索框描述想找什么，再点击“智能查找”；首选能力选 Claude 时使用本服务。普通结果保持可用；再次点击“取消智能”、修改查询、切换范围或隐藏面板，会停止采用旧请求的回复。在途服务请求可能仍然完成，软件不自动重试。

API 连接、认证或响应异常时，搜索页安静回到本地检索，不反复显示接口错误。可在“设置中心 → 服务连接 → 配置共用 Claude 连接”中点击“测试连接”，查看具体失败原因或成功耗时。测试使用当前填写但尚未保存的地址、模型、认证方式和密钥；密码留空使用已保存密钥，选择清除密钥后禁止测试。即使功能尚未启用，也能先测试再保存。

“获取模型”在后台使用当前未保存的地址、认证方式与密钥读取 `/v1/models`，不需要先填模型，不保存设置、不发送推理文本。最多 5 页、200 项，每页最多 256 KiB；不跟随重定向。关闭设置立即返回，旧结果不会进入重开的窗口；尚未结束的请求继续占用同一个槽。服务报告某强度不支持时会在设置中提示；没有能力信息的兼容网关仍允许手填，不能从模型名称猜能力。显式强度发送 `output_config.effort`；失败不会静默降级或重发，请选择“默认”作为明确兼容选项。

例如“我想暂时停止记录复制内容”可以推荐已有的“暂停记录”功能；“昨天保存的连接超时处理说明”可以改写为关键词并筛选历史。AI 推荐的功能只是可选结果，按 Enter 才执行。模型不生成虚构的历史条目或文件路径。

该功能使用 [Claude Messages API](https://platform.claude.com/docs/en/api/messages/create) 格式，仅发送本次查询、当前范围和公开功能目录，不上传历史正文、文件内容或图片。它将模型返回的短关键词、同义词和范围交给本地检索，此 Claude 功能不使用向量索引或文档 RAG。时间筛选按首次保存时间；今天、昨天及近 7/30 天使用 Windows 本地日期，近 7/30 天包含今天。

API Key 使用当前 Windows 用户的 DPAPI 保护后，随设置立即保存。AI 计划和回复只存在于内存，不因检索写入 SQLite。复制数据库到其他 Windows 账户或设备后，可能需要重新填写密钥。网络和加密原生测试在此 macOS 开发环境仅交叉编译，真实接口与 Windows 交互仍需验收。

## 统一设置中心

主面板“设置”、托盘“设置”和功能搜索“设置”都打开同一原生设置中心。宽窗口左侧选组，窄屏改为顶部选组；内容可滚动，底部打开与关闭始终可见。叶子编辑保存或取消返回原分组，校验失败保留原输入。从建议/记忆管理进入设置时，叶子编辑仍返回当前组；点击中心底部“返回记忆”/“返回建议”或关闭中心后，再回原管理页并保留反馈草稿。

| 分组 | 内容 |
|---|---|
| 常规与快捷键 | 主题，面板/剪贴板/截图三个快捷键 |
| 剪贴板与数据 | 暂停记录、排除应用、未固定历史保留 |
| 常用路径 | 观察、最近文档、排除目录；清空访问统计及不再推荐名单 |
| 智能查找 | Claude/语义能力开关、首选能力、索引范围与当前已知状态 |
| AI 管家 | 开关、模式、范围、整理说明与记忆；建议/记忆管理；高级调度参数 |
| 服务连接 | 检索与管家共用 Claude 连接；独立 Embedding 连接、模型与手动测试 |

未固定历史默认按“30 天未使用、最多 10000 条”保留，数据页显示实际已保存值。天数可填 1–36500，条数可填 1–1000000 的整数；减少限额会按现有策略清理未固定历史，固定内容和收藏保留。无效输入保留原草稿；既有非常规值未编辑时不会被其他设置修改重写。浏览设置不会清理数据、扫描正文或请求网络。

服务连接不重复提供能力开关；配置完整不代表连接成功，测试结果只对应当时输入。双智能能力关闭时，主按钮显示“启用 / 配置智能”。停用管家仍可管理已有建议与记忆，停用整理记忆则停止使用规则和记录反馈。管家的间隔、批量、模型轮次在“高级调度参数”，核心模式与范围仍集中在首个编辑入口。路径叶子无修改保存不发起检索，保存或清理后的后台通知也延迟主面板刷新；整个设置/管理返回链退出后才恢复本地查询。中心内转到建议或记忆管理、再进入设置时，会逐层返回原分组和来源管理页。叶子跨屏缩窄会按新客户宽度重排长标签、保留说明和连接状态，保持原输入控件与焦点。编辑设置后迟到的索引状态不会反复扫描；已经开始的索引结束后仍可刷新结果。关闭中心仅恢复本地查找，不额外校验索引。设置显示“更改已接收”表示进入现有异步保存流程；后台失败会在中心说明，旧保存通知不会冒充本次持久化确认。

## AI 管家（可选后台整理）

搜索“AI 管家设置”或从“设置中心 → AI 管家”打开。管家默认关闭，与“AI 按意思查找”开关独立，共用上面的地址、密钥、模型和推理强度。先配置 AI 接口，再明确启用管家；设置会说明所选摘要、路径及元数据将自动发送到该接口。不读取文件正文、图片、截图或二进制表示，不执行模型命令、不移动或重命名磁盘文件。

| 设置 | 行为 |
|---|---|
| 后台生成建议，由我确认（默认） | 结果保存在本机，稍后打开“整理建议”选择应用、编辑或忽略 |
| 后台自动应用 | 只填空别名，合并标签，保留人工别名和已有标签；不会应用此前留下的待确认建议 |
| 范围 | 收藏、固定剪贴板和外部路径（默认）；仅收藏和固定剪贴板；仅外部路径；或上述范围加普通剪贴板文本 |
| 间隔、批次、说明 | 30–3600 秒（默认 60），每批 1–8 条（默认 4），说明最多 512 字符 |

只整理启用后的新内容和新有效观察，不回放全部旧历史。排除应用和目录仍生效；路径范围还需要在“设置中心 → 常用路径”启用观察，管家不会替你开启监控。观察路径的别名和标签可用于本地搜索，仍保持外部观察身份，只有明确“收藏”才成为收藏项目。

主列表中的原内容一直可搜索、打开和复制。真正进入队列的内容显示灰色“待整理”，请求执行时显示“整理中”，建议生成后显示“有整理建议”；自动应用、确认或忽略后移除过程标记。未启用管家、范围外或未入队的旧内容不标记。路径仍用本地规则突出不同目录，确认前不提前使用 AI 建议的别名。

启用后列表上方提供可点击的“AI 管家”状态入口，统一显示整理中、建议数量、冷却、暂停或容量状态，点击查看本地建议；不逐行报错、不显示估算百分比或持续动画。状态由后台变更事件触发读取内存，合并在途刷新，隐藏主面板时不主动读取。AI 更新只修改当前行的别名和标签，保留顺序、选择、滚动、焦点与编辑；已在途的搜索仍接收结果并保留现有行的相对顺序，下次搜索恢复正常排序。显示状态不增加 SQLite 写入或网络请求。

“整理建议”立即读取本地完成结果，不等待接口、不因打开页面发网络。勾选多条应用或忽略，选择一条编辑别名和标签；别名最多 48 字符，建议标签最多 4 个、每个最多 24 字符，应用时与原标签合并。详情保留原名、已有元数据、最多 1024 字符的来源摘要及建议依据，路径另从本地按版本读取完整原样目标，可选择文字复制。来源变化时不把新路径配给旧建议，不让旧结果恢复已删除内容。页面刷新保留仍有效的选择、编辑和阅读位置；顶部来源被移除时保留邻近位置。过期提交的编辑会保留到你明确刷新。

点击应用/忽略先显示已提交，只有本次事务回执确认后才显示已保存；成功提示并列显示当前排队、冷却、暂停或容量状态。写入失败保留待写内容及编辑，可点击“重试保存”；建议从内存消失或旧保存通知都不能当成本次成功。关闭页面不会取消已提交的本地保存，后台可继续整理，稍后可重新查看。仅明确可重试的网络失败在前两次分别冷却 5、10 分钟、第三次暂停；认证和运行时启动失败首次即暂停。单批本地错误显示“需处理”，可明确重试或反馈，正常状态提供本地“刷新”。接口问题留在服务连接或管家页，普通搜索继续可用。

一次最多一个真实管家请求，没有待发网络队列。较长摘要使请求超过协议预算时，本批自动减少条数，其余继续排队，不计为接口失败。关闭管家、修改配置或退出会撤销旧结果，但在途请求直到实际结束仍占用网络槽；关闭窗口和退出不等待网络。管家缓存最多 256 条、2 MiB，待确认最多 128 条，先回收完成回执，满时保留原始内容和已有建议并显示容量状态。2 MiB 指整理缓存与 actor 活动任务的预算，页面快照、传输临时缓冲和整个进程 RSS 不包含在这个数中。缓存损坏只暂停管家，保留原始历史和损坏缓存；需明确修复缓存后重启，不会悄悄丢弃建议重新上传。

排队、结果和自动应用沿用约 55 秒开始、正常条件下 60 秒内的批量保存与正常退出保存；手动应用、忽略和设置立即提交。查询、绘制、本地详情读取不会写盘，无空闲空提交。有界完成回执被回收后，再遇到很旧内容可能重新整理。

## 可选语义检索（独立 Embedding API）

语义检索默认关闭，配置与 Claude 独立。打开“设置中心 → 服务连接 → 配置独立 Embedding 连接”，也可搜索“Embedding 服务连接设置”（旧名“语义检索设置”仍可搜索）。填写 OpenAI 兼容 Embedding API 地址、模型 ID 与 API Key 并保存，再到“智能查找”组启用语义查找、选择索引范围和首选能力。密钥由当前 Windows 用户的 DPAPI 保护；密码框留空保留原密钥，清除密钥同时关闭语义检索。保存只在本机校验配置与密钥，不发送网络请求。

Embedding 连接编辑页也提供“测试连接”，成功后显示向量维度和耗时。两个测试按钮每次仅发送一条内置测试文本，可能消耗服务额度；不发送历史或文件内容，不保存配置或写入索引。测试在后台运行，期间可取消关闭；重复点击不会叠加请求，关闭后的旧结果不再显示。测试失败原因只在设置表单显示；检索接口异常时继续使用本地结果，索引接口异常会停止本次更新，需手动再次启动。磁盘和保存错误仍会提示。

先从索引状态行或功能搜索执行“建立/更新语义索引”，再输入描述并点击“智能查找”。首选能力 Auto 有有效索引时优先使用语义，Semantic 始终使用该策略。输入时仍然即时执行普通本地检索；只有明确执行智能查找才发送查询。默认索引“固定内容与收藏”，可改为“全部文本”。索引不会因启动、复制、输入自动发起，已完成且输入未变的条目会跳过。源内容变化后，显式更新索引可补齐缺失或变化的向量。

**发送范围：**建立索引将选定范围的保存文本，以及保存的名称、别名、标签和路径发送给你配置的独立 Embedding 服务；查询仅发送本次描述。文档与文件夹只索引这些已保存元数据，不读取或解析文件正文；不发送图片和 HTML/RTF 二进制表示。每条派生输入最多 4096 字符（含元数据），原始内容不截断；仅有图片、没有可见文字的剪贴板不索引。

| 协议与预算 | 行为 |
|---|---|
| 地址 | 支持根地址、`/v1`、完整 `/v1/embeddings` 和代理前缀；远程要求 HTTPS，HTTP 仅允许本机 loopback |
| 请求 | Bearer Key；POST JSON 为 `model`、字符串数组 `input`、`encoding_format: "float"`；模型 ID 由用户填写 |
| 批次 | 一次最多 16 条、请求体最多 512 KiB；响应最多 2 MiB，向量维度 1–4096 |
| 结果 | 按响应 `index` 对齐输入；有限、非零且维度一致的向量；不显示服务错误正文，不自动重试 POST |

再次点击“取消智能”、修改查询、切换范围、打开设置或隐藏面板会立即撤销旧查询与已经采用的语义结果。普通检索可继续使用。在途网络可能仍完成，但过期回复不会进入结果。Claude 与语义查询互相撤销旧模式。

索引与查询独立；隐藏面板或编辑查询可以保留用户启动的索引。索引状态行或功能搜索中的“取消索引”、确认修改 Embedding 配置或退出会停止后续批次，保留已接收向量。每批收到存储接收回执后才继续；错误停止会话，需用户明确更新后再试。退出保存原文与已接收向量，不等待未完成的网络。

派生向量通过静态链接的 sqlite-vec **0.1.9** 存入本机 SQLite；按模型/地址 profile 和输入哈希隔离，删除及内容变化排除旧向量。检索合并词法与余弦候选，保持引擎的混合排序，最多返回 50 个真实保存条目。向量沿用约 55 秒开始、健康情况下 60 秒窗口的低频批量保存，派生缓存最多 4 MiB，压力时可提前提交；收藏与配置仍立即保存。

共享协议、worker、存储、排序和会话回归在 macOS 运行；Windows 本地 TCP/DPAPI fixtures 仅交叉检查编译，未执行 WinHTTP、DPAPI 或 GUI。真实服务的模型效果、费用和延迟以及 Windows 操作需实机验收；人工向量测试不能证明中文语义效果。

## 数据和保存

数据位于 %LOCALAPPDATA%/QuickPanel/quick-panel.sqlite3 及 SQLite 的同目录 WAL 文件。历史和收藏保存在本机，当前没有云同步或整个数据库的磁盘加密；Claude 查询与语义查询/索引的发送范围见上节。来源应用声明的敏感剪贴板标记会被排除，也可以手动排除应用；这依赖来源应用正确提供标记。

- 历史进入内存后立即可查、可复制和粘贴。默认约 55 秒开始批量提交，预留提交裕量；正常磁盘响应下保存窗口不超过 60 秒，连续复制不会延期。
- 收藏及其删除、确认后的配置立即保存。使用次数合并更新，随批次保存。
- 没有数据变更时不提交空事务，不周期性重写配置、日志或缩略图。
- 图片原始表示与数据库引用在同一个事务内保存。缩略图仅作内存缓存，不因预览写盘。
- 图片保留的总负载上限 8 MiB；有 PNG 原图时，过大的可选 DIB 表示可跳过而保留 PNG，只有 DIB 且超预算仍不支持。预览源上限 100 MP，缩略图长边最多 1024、输出最多 4 MiB；可选粘贴兼容 DIB 最多 64 MiB，超限保留原图并安静退回可用格式。这些是应用自身数据预算，不是进程总 RSS 的承诺。
- 待保存内容及捕获队列各有 16 MiB 预算，单条捕获总表示和派生文字上限 8 MiB；接近预算时提前保存。超限时说明未记录，不截断当前剪贴板。
- 正常退出先排空已接受任务并保存全部待保存内容，收到成功确认后才结束进程。失败时等待用户重试或取消退出，缓存继续保留；取消后恢复后台保存。
- 任务管理器强制结束、系统故障或断电可能丢失尚未提交的数据。Windows 结束会话执行有界保存，不能等同正常退出。

备份时先正常退出程序，再复制整个 QuickPanel 数据目录。

    powershell -ExecutionPolicy Bypass -File scripts/build-windows.ps1 -Node <Node24路径> -Pnpm <pnpm.cjs路径> -NodeAssets <Windows资产目录>

    cargo run --release -- --core-check

    cargo run --release -- --benchmark 100000

core-check 使用临时数据库验证保存前可检索、保存前磁盘没有历史条目，以及退出后能够恢复。benchmark 写入明确数量的混合中文、拼音、路径记录，输出 100 次核心查询的 p50、p95 和最大值；不包含 Windows 窗口与渲染延迟。基准准备阶段主动分批保存，以限制输入队列内存，不代表日常自动保存频率。

自动测试覆盖低频提交、真实 SQLite 故障重试、退避与缓存预算、退出恢复、中文短查询和拼音检索、格式解析与面板状态。Windows CI 配置位于 .github/workflows/windows.yml；本地交叉构建成功不等于该 CI 已运行。

### 构建完整便携包

开发构建使用固定 Node 24.19.0、pnpm 11.25.0 与仓库 lockfile，依赖安装禁用生命周期脚本。显式运行 `python3 scripts/fetch-node.py --download --output <资产目录>` 获取并核验官方 Windows Node；应用启动不会执行下载。
