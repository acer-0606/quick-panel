# 交互与设置清晰化设计

用户已在完整交互审查后要求“你指出的问题都修复一下”。本设计落实该审查及六组设置方向，不重复请求批准。当前基线为 `2bcb7594ec6c18a4dc83c81699cb6185e4fadc0c`，继续原目录和 `codex/quick-panel` 分支。

## 用户结果

用户应能判断当前在使用哪种能力、哪些功能关闭、操作是否完成、失败后如何修正。表单错误保留输入，控件含义与实际写入一致；搜索、托盘、主面板的同名入口对应同一目的地。已关闭能力不自动执行，历史管理可以保留，但必须说明停用及当前可做的动作。

## 全局约束

- 交互与文档使用中文；Windows 10/11 x64 为主要产品平台，继续 Rust/Win32 原生控件、现有 theme、SQLite 和固定 Pi 运行时，不新增 WebView、Electron、UI框架或全局热键。
- 保持历史/后台派生数据的低频批量写入和正常退出保存；收藏、配置、人工确认立即保存。只读状态、绘制、设置导航不提交事务、不读正文/BLOB、不请求网络。
- 不访问真实 API、密钥、用户数据库、正文、剪贴板或屏幕；验证使用合成数据。macOS 的共享/进程测试与 Windows 交叉编译不声称 Windows 实机运行。
- 保留已有实际任务占用、代次/来源/版本/回执守卫、IME原生编辑、草稿保留、滚动位置、固定footer和DPI行为；关闭窗口/退出不等待网络或join子进程。
- 关闭AI检索不连带关闭独立AI管家；关闭记忆停止使用已有记忆和新反馈，明确告知而不悄悄重开。关闭管家停止后台整理，允许管理已有建议与记忆。
- 用户明确发起的API失败只产生本次安静的状态说明，不重复弹错、不显示服务原始正文；提供对应设置/连接测试路径。
- 同时最多一个实现者和一个Cargo命令；固定 `CARGO_INCREMENTAL=0 CARGO_BUILD_JOBS=1 CARGO_PROFILE_DEV_DEBUG=0 CARGO_PROFILE_TEST_DEBUG=0`。定点回归后才扩大检查，完整共享全套在最终集成源码上执行一次，后续仅新变更/失败才重跑必要范围。

## 设置与视觉结构

设置中心包含：常规与快捷键（主题及三组热键）、剪贴板与数据（记录/排除/保留）、常用路径（观察/排除/明确清理）、智能查找（能力开关/首选/索引状态与范围）、AI管家（模式/范围/建议/记忆/高级参数）、服务连接（共用Claude兼容API、独立Embedding连接、模型和连接测试）。

只读中心不复制秘密数据、不自动请求服务；服务配置与功能启用职责清楚，Claude服务供检索与管家共用。可以复用原生叶子表单，但导航需明确返回，保持选择上下文，不能让相同“设置”入口落在不同范围。截图与查看建议属于可搜索操作，不夹在设置分类列表中。

原生设置中心采用左侧分组导航、右侧分组标题/简短说明/当前状态和操作，固定底部关闭/返回。左对齐，沿用Segoe UI 15 logical px及现有明暗色：浅色背景#F6F7F9/表面#FFFFFF/正文#1E2530/辅助#6A7584/强调#2B70DE/选中#E8F1FF；深色背景#1E2024/表面#272A2F/正文#EEF0F4/辅助#A5ADBB/强调#589DF5/选中#283A51。用留白和分组表达关系，不添加动画、装饰卡片或新图形依赖。高级调度参数集中放高级区域；模型与推理强度仍可配置。

## 实施取舍

1. 反馈模式移除无效启用/确认控件，明确保存即生效；记忆管理仍能停用或确认规则。代价是反馈页不新增“暂存未启用反馈”模式。
2. 将“暂不处理”改为准确的“忽略建议”，保留当前版本终结语义；代价是本轮不提供稍后队列或恢复已忽略建议的新功能。
3. 路径清空保留原合同，完整说明同时清除统计与不再推荐名单；代价是暂不能只重置访问计数同时保留屏蔽名单。
4. 保留设置接受正整数，天数上限36500、未固定条数上限1000000；拒绝0避免被误解为无限保留，原有非常规值不随其他设置修改被重写。代价是本轮UI不提供无限保留选项。
