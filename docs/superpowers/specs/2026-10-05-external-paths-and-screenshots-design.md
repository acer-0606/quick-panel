# 外部常用路径与区域截图

用户要求自动发现本工具之外经常打开的文件夹/文档，并将截图以 PNG 或 JPG 放入剪贴板；最新澄清以非本工具的文件夹访问为主。沿用上一轮提出的本地频率推荐和原生截图方案，继续当前目录与开发分支。

## 用户行为

- 在设置启用“外部路径推荐”后，主要观察前台 Windows 资源管理器正在访问的文件夹，无须先添加收藏。Windows 最近文档作为可单独关闭的补充来源。本工具内的打开记录不能替代外部采集。
- 空查询展示至多 5 个自动推荐；输入名称、路径、中文/拼音时，自动路径与已有功能、历史和收藏一起可检索，文件夹/文档范围有效。推荐明确标注“自动推荐”，最多 10 项，并提供打开、定位、收藏、不再推荐；自动记录与人工收藏独立。
- 排名依据带时间衰减的本地访问频次；不因每次访问调用 AI，不上传自动采集的路径。自动路径不加入既有默认收藏语义索引；明确收藏后遵循原有索引规则。
- 路径推荐设置可启用/停用、切换最近文档、排除目录（含子目录）及清空统计。新旧安装默认关闭此可选采集功能，界面说明开启后记录哪些来源。关闭后停止采集并隐藏自动推荐，原有收藏不受影响。
- 搜索“截图”或从菜单执行区域截图，拖动选区确认后得到可粘贴的 PNG 图片；兼容位图按既有预算提供。Esc/右键/零面积取消不改变剪贴板。首版交付 PNG 剪贴板，JPG 文件导出和标注不是此请求的必要部分。
- 截图可配置独立快捷键，默认不注册，不占用系统 Win+Shift+S。截图之前隐藏面板，支持负坐标多屏和不同 DPI。只有历史记录开启且来源未被排除时，截图进入现有历史。

## 外部采集的边界

这里统计“观察到的有效访问”，不是每次底层文件读取的审计。资源管理器来源只接受可确定的前台活动视图与实际文件系统路径；不以窗口标题猜路径，不把切换回同一窗口反复计次。资源管理器标签页要验证活动视图可见性；无法确定时跳过，不错记隐藏标签页。第三方文件管理器和应用内部目录导航首版不承诺覆盖。

采用有界后台探测：启用时每 2 秒只检查前台窗口身份；前台为资源管理器才请求 Shell 当前视图路径。一次真实探测在途，不叠加阻塞 COM 调用。路径稳定至少 1.5 秒后记录一次；同一规范路径 30 秒内来自不同来源的重复通知合并。非前台/关闭/配置变化会使旧探测失效。退出不等待可能卡住的外部 COM。

最近文档读取当前用户 Recent 中的快捷方式，使用目录变更通知触发增量解析，初次建立基线不假称已有文件被重新打开。每轮最多处理 16 个变化链接，基线最多 2048 个；不调用 Resolve、不打开目标、不读取文档正文、不探测网络路径。仅用快捷方式存储的目标/属性，跳过带启动参数或无法确定的目标。Windows 最近文档依赖应用上报，因此无法完整覆盖所有文档打开。

## 内存、排名与持久化

- 自动记录使用独立的 `path_activity` 表与内存状态，不插入 `items`/FTS/向量表、不自动创建收藏。表首次有变更时在原有事务中创建，关闭功能的旧库不因查询创建派生表。
- 最多 1024 个有效路径和 128 个“不再推荐”记录；路径最多 2048 个 UTF-16 单元，总路径缓存最多 2 MiB。接收观察批次至多 32 项，并对排队数据设有界预算，不能挤占剪贴板队列或阻塞 UI。
- 使用按 7 天半衰期衰减的访问权重。资源管理器访问权重 1，Recent 文档更新权重 0.5；时钟回拨不能产生负数、无限权重或无休止去重。同分按最近访问和规范路径稳定排序。90 天未访问的自动记录可在有变更的保存中清理；不清理手动收藏。
- 规范化仅做 Windows 路径语法处理，不调用磁盘 canonicalize；接受绝对盘符路径及 UNC，拒绝设备/命名空间、相对路径、NUL/控制字符、ADS。排除目录按完整路径组件判断，不能把 `C:\\Work` 错用于 `C:\\Worker`。
- 路径统计复用历史约 55 秒开始、正常 I/O 下 60 秒内的事务窗口，持续访问不能延期；仅提交变化行。收藏、配置、明确“不再推荐”及清空立即保存。空闲无变更不写盘，查询不提交。
- 路径统计和已有内容在同一个保存事务中完成；失败保留待提交状态及退避；正常退出保存已接收统计，取消退出恢复定时保存。路径统计本身不改变语义源代次，也不触发整库语义状态扫描。

## 界面与接口衔接

自动路径使用独立的列表 entry，不伪装成已有保存条目。其打开/定位复用后台动作和目标票据，收藏打开现有表单由用户确认。迟到结果必须检查查询请求、范围、配置代次和菜单目标；新的路径统计刷新不能撤销同身份的合法用户操作。

路径状态在引擎中检索，并沿当前 latest-only Search/AiSearch/SemanticSearch 查询发送请求编号一致的路径候选事件。Claude 改写可在本机匹配这些候选，但网络请求不包含它们；语义检索对自动路径只补充本地词法匹配。手动收藏的相同路径优先，显示时去重，最多 50 个总结果。

截图在调用后才分配资源。透明原生选区层在确认后隐藏，捕获选区像素；不需要常驻抓屏、不创建临时图片文件。选区原始像素预算 64 MiB，PNG 交付预算 8 MiB，尺寸与乘法必须检查溢出。编码放后台，一次实际任务在途；失败/取消释放占位。后台完成时检查操作代次和剪贴板序号，不能覆盖用户其间复制的新内容。分配/编码完成再修改剪贴板；截图历史只接收一次，沿原低频保存。

## 验证

共享测试使用真实 SQLite 验证外部观察首次可查但未提前落盘、连续观察不延期、失败重试、退出恢复、关闭与排除、不会自动入收藏/语义索引、路径规范化/去重/排名/限制，以及截图选区、预算与取消门控。Win32 用 all-targets 严格 Clippy 和 Release 交叉构建；Windows Explorer/标签页/Recent/多屏截图/剪贴板仍需实机验证，不能把编译称为运行通过。禁止通过测试监听用户真实目录、抓取真实屏幕、读取用户密钥或调用付费接口。
