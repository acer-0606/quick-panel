# Windows 本地快捷工具设计草案

本工具面向 Windows 日常办公，把历史剪贴板、常用文件夹和快捷文档放进一个快捷面板。首版以响应速度、低常驻占用、低频磁盘写入和便捷操作为主要目标，同时提供清楚、整洁的外观。

本文记录用户于 2026-10-02 确认的实现方向。首版现已按 Rust、Win32 原生控件和 SQLite 路线实现；实际验证结果与尚待 Windows 实机测量的指标见[首版验证记录](../../verification.md)。

## 已确认的要求

- 历史剪贴板、常用文件夹、快捷文档统一检索和操作。
- SQLite、图片、配置、日志和缓存都要尽量减少磁盘写入频率。
- 新历史可先缓存在内存中，保存目标窗口为 60 秒；收藏和配置在用户确认修改后立即保存。
- 正常退出程序时，把所有已接受、尚未保存的数据写入磁盘，保存成功后才结束进程。
- 界面有一定美观性，同时保持键盘、鼠标和添加收藏的便利性。

## 首版功能

剪贴板记录常见文本、图片、文件列表和富文本表示，支持搜索、固定、复制、粘贴及纯文本粘贴。相同内容合并最近时间和使用信息；格式不同的富文本不能仅凭纯文本相同就丢弃。提供暂停记录和应用排除设置。

常用文件夹与快捷文档共用收藏结构，保存名称、目标、别名、标签和打开方式。拖入面板或点击添加按钮即可收藏；文件夹用资源管理器打开，文档用默认应用或用户指定应用打开。文件失效时保留名称和原路径，提供重新定位入口。

首版的文档功能是快速打开已有文档。后续可添加项目收藏组，把项目目录、文档和固定内容放在一起；完整编辑器、插件市场、云同步及 AI 检索暂不进入首版。

## 面板外观

默认面板约 680 × 480 DIP，按屏幕可用空间调整。顶部为搜索框，其下为全部、剪贴板、文件夹和文档四个范围；中间是结果列表，底部显示当前选中项的主要动作和快捷键。预览默认收起，需要时向右展开。

跟随系统浅深色，也允许手动选择。浅色用柔和灰白，深色用炭灰；系统字体、细边框、轻阴影和少量强调色形成层次。强调色用于选中项与焦点。保证高对比度和清晰的键盘焦点，避免依赖颜色表达状态。

搜索框使用原生文本控件，保留中文输入法、选区和无障碍行为。列表只加载可见结果；基础外观优先使用原生控件和轻量绘制，不把大面积模糊、持续动画和网页渲染作为必要依赖。按每个显示器的 DPI 布局，窗口保持在当前工作屏幕的可用区域。

## 操作规则

| 操作 | 行为 |
|---|---|
| 全局快捷键 | 呼出面板并聚焦搜索框；可配置，注册冲突时提供替换入口 |
| 另一组全局快捷键 | 直接进入剪贴板范围；可配置，保留系统 Win+V |
| 上下方向键 | 选择结果 |
| Enter | 文件与文件夹打开，剪贴板粘贴；底部明确显示将执行的动作 |
| Shift+Enter | 对剪贴板执行纯文本粘贴 |
| Ctrl+C | 搜索框有文本选区时复制该文本，否则复制当前结果；不自动粘贴 |
| Ctrl+K | 打开动作菜单，包含收藏、复制路径、打开所在目录和打开方式 |
| Ctrl+1 至 Ctrl+4 | 切换四个搜索范围 |
| Esc、关闭按钮、面板失焦 | 收起面板，程序继续在托盘运行 |
| 托盘退出程序 | 进入保存退出流程 |
| 单击与双击 | 单击选择，双击执行；右键显示同一套动作 |
| 添加按钮或拖入文件 | 添加收藏，随后可编辑名称和别名 |

输入法组合期间，Enter 和 Esc 先交给输入法，不执行结果、不收起面板；方向键用于候选词选择。中文、拼音、缩写和混合路径纳入检索验收。

空查询展示固定项和最近使用；有查询时优先匹配精确别名和名称，再考虑相关度与使用习惯。当前结果展示期间保持选中项稳定，后台新增历史通过轻提示告知，不把用户正在选择的结果顶走。

## 内存和低频保存

新历史先进入内存暂存区和增量检索结构，立即可搜索、复制、粘贴。搜索合并磁盘已保存数据与内存增量；尚未保存的修改与删除也必须生效。

保存期限以最早未保存历史为基准，连续复制不能重置计时。正常磁盘响应下调度器应留出提交时间，使保存窗口不超过 60 秒；磁盘故障或阻塞导致逾期时保留待保存记录并提示，不能宣称仍然满足窗口。

单个后台写入器合并待保存变更，然后开启短事务，统一保存内容、检索索引、去重信息和使用统计。每项变更带有版本，提交成功后只清除已提交版本；提交期间的新记录或同一条目的新修改仍留在下一批中。不能长期持有写事务、逐条执行写入后只延迟提交。

| 数据 | 磁盘策略 |
|---|---|
| 新历史及其图片原始数据 | 随历史批次保存；正常退出前全部保存 |
| 收藏和配置 | 用户确认操作后立即提交，仍经过同一个写入器 |
| 使用次数及最近使用时间 | 内存按条目合并，随批次保存 |
| 缩略图和可重建预览 | 使用有界内存缓存，首版不建立磁盘缩略图缓存 |
| 日志 | 默认有界内存缓冲，用户导出时才写文件 |
| 无变更状态 | 不提交空事务，不周期性重写配置，不做定时 VACUUM |

缓存必须有字节上限；图片使缓存接近上限时允许提前批量保存。首轮拟定待保存内容预算 16 MiB、单条捕获内容上限 8 MiB、解码预览缓存预算 16 MiB；这些值以实测调整。超限内容保留当前系统剪贴板，界面说明该项未记录，避免悄悄截断。文件列表保存路径和引用，不复制文档本体。

首版建议把需要持久化的剪贴板二进制表示存入 SQLite BLOB，并同元数据置于同一事务，减少逐条创建图片文件及跨文件提交的复杂度。原始图片不加载进结果列表；预览异步解码并受像素数与内存预算限制。若实测发现 BLOB 写入量或数据库增长不可接受，再比较独立附件方案，后者必须另行保证附件同步及引用一致性。

SQLite 使用 WAL 和 synchronous=FULL，降低提交频率的同时保留已提交批次的持久性。使用已包含 WAL 修复的版本。查询临时数据使用有界内存，避免搜索排序产生磁盘临时文件。checkpoint 由同一后台调度器在空闲时执行，并设置 WAL 大小及维护等待上限；不每批强制截断 WAL。短读事务避免妨碍回收。

低频指应用产生写入工作的频率；一个批次仍可能包含多次文件写调用。验收同时统计事务数、同步次数、文件写调用和写入字节，不宣称一分钟只发生一次物理磁盘写入。

## 正常退出流程

退出状态依次为运行、停止接收、排空已接受任务、最终保存、清理资源、结束。重复退出请求合并成同一个流程。

1. 托盘退出命令进入退出状态，暂停接收新的采集和修改，但暂不拆除窗口、快捷键与监听器。
2. 排空已经接受的剪贴板读取、解析和索引任务；所有最终数据进入保存队列。正在进行的批次先完成，最终保存请求排在其后。
3. 将未提交内容、图片、检索数据和统计写入事务；确认已提交批次完成必要同步。可重建的缩略图及内存诊断日志无需持久化。
4. 收到最终保存成功回执后，关闭数据库并释放监听器、快捷键和托盘窗口，随后结束进程。不能发送保存任务后立即退出。
5. 保存失败时保留尚未保存的数据，显示重试和取消退出。取消后恢复采集与交互，并补采当前剪贴板；重试使用稳定条目和批次标识，不能产生重复历史或重复累计。

通常无需弹出确认框；保存耗时超过短暂等待时显示正在保存并保持界面响应。退出取消前已经成功保存的批次仍然有效。

Windows 注销、关机和系统更新结束会话另行处理：WM_QUERYENDSESSION 快速回应，WM_ENDSESSION 确认结束后执行有界自动保存；会话取消则恢复工作。普通退出的等待和错误对话框不直接用于系统关机。强制结束、系统故障及突然断电仍可能丢失内存未提交历史，这与正常退出的保存保证分别验收。

## 组件分工

| 组件 | 职责及边界 |
|---|---|
| Windows 运行层 | 托盘、全局热键、窗口、生命周期与系统消息 |
| 剪贴板采集 | 事件监听、内容快照、自身写回抑制和采集过滤 |
| 搜索服务 | 已保存数据与内存增量检索、中文支持、排序与请求取消 |
| 保存服务 | 单写入器、期限调度、事务、同步、checkpoint 与恢复 |
| 收藏服务 | 文件夹和文档的统一模型、编辑、目标验证与重新关联 |
| 动作服务 | 打开、复制、焦点恢复和自动粘贴 |
| 面板界面 | 可见结果、选中状态、动作提示、添加收藏和按需预览 |

采集使用 Windows 剪贴板变化消息。读取争用时做有界重试，内容尽快复制到应用持有的内存，再交给后台处理。自动粘贴先验证原目标窗口及焦点；遇管理员窗口的权限边界或焦点恢复失败时保留已复制内容，提示手动粘贴。

## 验收目标和验证环境

下列指标尚未实测。固定 Windows 机器、系统版本和 Release 构建，常规档用一万条混合中英文历史与两千个收藏，另用十万条做压力档。

| 项目 | 首轮目标 |
|---|---|
| 热键到面板可输入 | p95 不超过 80 ms，至少 200 次 |
| 输入到前 50 条结果显示 | 常规档 p95 不超过 30 ms；压力档不超过 60 ms |
| 常驻内存 | 常规档空闲工作集目标不超过 80 MiB，另报告预览和待保存缓存峰值 |
| 空闲 CPU | 五分钟平均不超过单核的 0.5% |
| 空闲磁盘写入 | 无待保存变更及维护需要时，不主动产生周期性写入 |
| 常规历史保存 | 按最老变更的 60 秒窗口调度，不因持续复制延期 |
| 正常退出 | 重启后可恢复退出前所有已接受且需要持久化的数据 |
| 连续运行 | 八小时使用及一千次呼出收起，无持续资源增长 |

验证覆盖中文输入法选词、DPI 和多屏、大图与长文本、多文件剪贴板、快速连续复制、焦点改变、权限受限粘贴、磁盘满、提交失败后重试、保存期间新增记录、取消退出、文件移动及系统会话结束。

当前开发环境为 macOS。可在本机验证共享数据、检索和保存逻辑；Windows 窗口、热键、输入法、退出消息和资源指标必须在 Windows 实机或相应测试环境验证。

## 调研依据

- [Flow Launcher](https://github.com/Flow-Launcher/Flow.Launcher)提供 Windows 文件入口、拼音检索、预览和快捷动作；剪贴板由社区插件提供。
- [Ditto](https://github.com/sabrogden/Ditto)可参考剪贴板格式处理及回到原窗口的粘贴流程。
- [Wox](https://github.com/Wox-launcher/Wox)可参考统一搜索、范围前缀、别名和动作面板。
- [微软 windows-rs](https://github.com/microsoft/windows-rs)提供 Rust 调用 Windows API 的绑定。
- [Windows 剪贴板](https://learn.microsoft.com/en-us/windows/win32/dataxchg/using-the-clipboard)说明格式监听和变化消息。
- [SendInput](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput)说明输入注入及权限边界。
- [SQLite WAL](https://www.sqlite.org/wal.html)和[同步设置](https://www.sqlite.org/pragma.html#pragma_synchronous)说明事务持久性及 checkpoint。
- [SQLite FTS5](https://www.sqlite.org/fts5.html#tokenizers)说明默认分词与短子串检索限制，中文查询需要专门处理。
- [Windows 会话查询](https://learn.microsoft.com/en-us/windows/win32/shutdown/wm-queryendsession)和[会话结束](https://learn.microsoft.com/en-us/windows/win32/shutdown/wm-endsession)说明关机与注销处理。
