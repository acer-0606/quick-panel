# AI 管家与路径辨识

用户已确认路径差异突出、别名检索、AI 辅助起名，并进一步要求覆盖各种保存内容的分类与别名。最新选择：所有整理都后台执行，设置中选择自动应用或后台生成建议后空闲时保存；API 可获取模型列表，选择具体模型和推理强度。

## 用户行为

- 路径列表在内存里比较本次最多 50 项结果。差异目录放在前面，别名优先，完整真实路径用于打开、复制及预览。此前实现 2790380 纳入最终审查。
- 新增“AI 管家设置”和“整理建议”功能及菜单，无新增默认快捷键。管家默认关闭；启用说明会自动发送所选范围的文本摘要/路径及元数据到已配置的 Claude 兼容 API，不读取文件正文、截图或二进制内容。
- 模式 `Suggest`（默认）只生成待确认建议；`Automatic` 后台自动应用。两种模式都不阻塞搜索、文件打开、剪贴板采集或退出，不要求用户停留等待网络。
- 范围可选：收藏+固定剪贴板+外部常用路径（默认）、仅收藏+固定剪贴板、仅外部常用路径、上述范围加普通剪贴板文本。排除应用和排除路径仍生效。仅处理启用后的新内容/新有效观察，不自动回放全部旧记录。
- 可配置间隔（30–3600 秒，默认 60）、每批数量（1–8，默认 4）和整理说明（最多 512 字符，例如“按项目和用途分类”）。复用已有 Claude endpoint、加密密钥、模型配置。
- AI 检索开关与管家开关独立：关闭“AI 按意思查找”不影响已明确启用的管家；关闭管家才停止自动整理。二者共用 API 配置，均默认关闭。
- 分类复用 tags，生成最多 4 个简短标签；别名最多 48 字符。AI 返回的只有元数据建议，不允许生成或执行命令、移动/重命名磁盘文件、删除内容。无法判断用途可不给别名，不把 a/b 代号编造成业务名称。
- 自动模式只填空别名，保留已有人工别名，合并标签而不删原标签。确认模式在建议页可修改、选择应用或忽略；明确保存后立即写盘。建议只能应用到未发生相关内容/元数据变化的同一个源。
- 外部常用路径也能拥有可搜索别名和标签，仍保持外部观察身份；不会自动转成收藏。
- 待确认页展示已生成结果，获取本地快照不发网络请求；支持多条选择应用/忽略、选中一条编辑别名和标签，显示积压和失败/退避状态。普通搜索页不反复报 AI 错误。

## API 与模型

- 保持 Claude Messages 格式。AI 设置增加“获取模型”按钮、可输入的模型下拉框、推理强度下拉框（默认/low/medium/high/xhigh/max）。获取模型使用同一地址与当前输入或保存的密钥，GET /v1/models；输入完整 /v1/messages 地址时正确替换资源尾段。
- 列表操作异步且不保存设置、不产生推理请求。最多 5 页/200 模型、每页响应最多 256 KiB。仅使用服务返回的同源 cursor 组装后续 URL，不跟随远程 URL 或重定向。支持常见 data:[{id,...}] 兼容列表；缺少 capabilities 时保留手动配置能力。
- 默认推理强度不发送 effort 字段；显式选择发送 output_config.effort。仅依据服务返回的 capabilities.effort 报告已知不支持情况，不用硬编码模型名猜能力。Messages 响应可忽略有界的 thinking/redacted_thinking 块，但仍拒绝 tool_use、非完整输出和不符合结果 schema 的内容。
- 搜索和整理共用所选模型/effort；测试连接验证当前未保存的设置。单请求不自动重发；密钥用已有 DPAPI 和擦除包装，错误不包含服务正文/密钥/私有内容。
- 官方依据：https://platform.claude.com/docs/en/api/models/list 与 https://platform.claude.com/docs/en/build-with-claude/effort （2026-10-06 查阅）。

## 后台与持久化

- SQLite actor 只做本地短任务，网络在独立有界 worker；一次最多一个真实管家请求，无隐藏待发网络队列。关闭或改配置、清空来源、退出撤销旧结果；取消不能提前释放实际网络占用。关闭界面和退出不 join 网络线程。
- 新增来源入队按内容指纹去重；指纹不包括使用次数/访问时间或 AI 自己生成的别名标签，避免反馈循环。应用另用源版本检查，拒绝已删除、改路径、改元数据或不再允许范围的旧建议。
- 管家记录最多 256 条、内存/序列化数据预算 2 MiB，待确认建议最多 128 条。先淘汰处理完成的旧回执，不静默丢弃已有待确认建议。预算满时保留原始内容并暂停接收新的整理任务，状态可见。去重回执淘汰后再次遇到很旧的内容可能重新整理，属于有界缓存的限制。
- 每项文本上下文最多 1024 字符，每批最多 8 项。来源快照不带 BLOB；长源内容只用于截取摘要，不为 UI 批量加载图片。整理备注与数据作为 JSON，不作为系统指令。
- 排队记录、待确认结果、自动应用和回执沿用现有约 55 秒启动/60 秒健康上限批量写盘及正常退出 flush。用户确认/忽略和设置立即保存。无新网络/磁盘工作出现在查询或绘制热路径；无空闲空提交。
- 状态持久化与别名/标签应用属于同一 repository 事务，提交失败保留待写状态重试。新表惰性创建，旧数据库配置缺字段使用默认值。
- 连续失败退避至少 5 分钟，再 10 分钟，第三次暂停自动处理；设置修改或管家页面“重试”恢复。失败只影响管家，保留本地搜索。重启不绕过已保存的失败冷却/暂停状态。
