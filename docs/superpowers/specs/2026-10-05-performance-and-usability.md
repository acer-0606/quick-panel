# 性能与便捷性优化

用户在审查后要求“都修复一下”，批准上一轮全部建议。本次继续在指定 quick-panel 文件夹和 codex/quick-panel 分支实施。

## 目标与约束

- Windows 原生 Rust/Win32 + SQLite/sqlite-vec，保持既有配置及数据兼容。
- 历史默认约55秒开始提交、健康情况下不超过60秒；收藏和配置立即保存，正常退出提交已接收数据。不得通过每次查询、预览或状态刷新写数据库来优化。
- 普通输入仅本地检索；智能检索、建立索引和连接测试仍由用户明确触发。接口失败安静回退；存储错误仍提示。不开真实收费服务，不使用用户密钥验证。
- 搜索保留完整召回，快速输入只保留最新待处理查询；长候选扫描允许取消和响应到期保存，可靠命令不得丢失。
- 源内容扫描代次与事务次数分离，纯向量保存不从头重扫；语义范围/pin过滤避免关联JSON重复扫描；小事务避免整库维护，删除及保留仍原子一致。
- 文件检查与Shell操作在有界后台执行，迟到结果不能操作已切换的目标。预览同内容去重并保持滚动位置；图片按预览尺寸缩放，长文本可滚动和选中复制。
- 图像捕获在已有可用PNG时允许跳过超预算冗余DIB；纯DIB保留现有预算。保留实际保存格式的明确信息，PNG恢复按需生成有界兼容DIB，不能无上限扩张内存。
- 主界面只有一个“智能查找”按钮。常规设置提供自动、功能与关键词（Claude）、内容语义（Embedding）选择；自动在已建立语义索引时优先语义，否则使用已启用Claude；只有Embedding时明确引导建立索引。功能仍始终参与本地搜索。
- 索引状态展示未建立、已索引条数、待更新；零有效向量不发送无效查询请求，建立索引仍明确点击。
- 固定剪贴板可编辑名称、别名、标签，立即保存，保留原始文本和全部已保存格式，重新复制不能抹掉自定义名称。
- 重新从外部唤起时选中上一次查询以便覆盖；内部刷新/切换预览不抢选区。结果提供命中片段、来源和保存时间；片段只在内存，不污染原数据。

## 验证

共享行为使用真实SQLite和受控线程回归，覆盖旧查询合并、可靠命令不丢、扫描取消及保存期限、向量保存游标前进、维护触发、pin过滤、元数据保存和原内容保留、片段与状态。Windows进行all-targets严格Clippy和Release交叉构建；原生运行未验证的项目必须明确记录。磁盘空间紧张，Cargo与大型夹具串行执行。
